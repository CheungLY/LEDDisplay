# LEDDisplay
This LED Display will be using a LED Matrix to work as signage that scrolls through text that is given.

The design I have built here is the is simply the microcontroller section. This makes sure that the microcontroller can communicate with the LED Matrix correctly, such as providing the correct logical high with more than 3.5 volts in the LED Matrix and 3.3v in the XIAO.
